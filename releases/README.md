# RidePulse Android APK

Download `RidePulse-latest.apk` on an Android phone and install it.

Android may show an "Install unknown apps" warning because this APK is installed directly from GitHub instead of Play Store. Allow install for your browser or file manager only if you trust this repo.

After installing:

1. Open RidePulse.
2. Log in with your rider account.
3. Grant location permissions.
4. For ride tracking reliability, allow background location and disable battery optimization for RidePulse.
